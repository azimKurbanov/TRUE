# TRUE FITNESS - Landing Page

React, Vite va Tailwind CSS asosida yaratilgan TRUE FITNESS veb-sahifasi.

## Loyihani ishga tushirish

1. Qaramliklarni o'rnatish:
```bash
npm install
```

2. Dasturni ishga tushirish:
```bash
npm run dev
```

3. Ishlab chiqarish (production) uchun build qilish:
```bash
npm run build
```

## Texnologiyalar
- React 18
- Vite 5
- Tailwind CSS 3
